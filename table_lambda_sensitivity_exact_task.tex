\paragraph{Interpretation.} The exact-task multinomial validation confirms the pattern observed in secondary diagnostics (Table~S7): Pure-DCE ($\lambda = 0.00$) achieves the best held-out predictive performance, and predictive accuracy monotonically degrades as $\lambda$ increases. EFR at $\lambda = 0.25$ represents a conservative operating point that retains 25\% LLM weight for narrative extension capability while recovering most (within 1.3\%) of the DCE model's predictive accuracy. This validates the operating point selection independently of the 64-state structural diagnostics and the 809-row partial-support binary sensitivity analysis.
